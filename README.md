# Excel-UPI-Transaction-Analysis-Dashboard

## Project Overview
The UPI Transaction Analysis Dashboard is an interactive Excel-based dashboard designed to analyze and visualize UPI transaction data. It provides insights into transaction volume, transaction amounts, payment applications, transaction statuses, merchant categories, and potential fraud.

## Key Features
- **KPI Overview:** Total Transactions, Total Transaction Amount, Cashback, Success Rate, and Suspected Fraud.
- **Transaction Trends:** Daily transaction amount analysis.
- **UPI App Analysis:** Comparison of transactions across PhonePe, Google Pay, Paytm, Amazon Pay, BHIM, and other apps.
- **Transaction Status:** Analysis of successful, failed, pending, and refunded transactions.
- **Geographical Analysis:** State-wise transaction amount distribution.
- **Bank Analysis:** Comparison of transaction amounts across different banks.
- **Transaction Type Analysis:** Insights into P2M, P2P, bill payments, online shopping, recharge, and other categories.
- **Time-Based Analysis:** Hourly and day-wise transaction patterns.
- **Interactive Filters:** Slicers for City, Gender, Merchant Name, and Merchant Category.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Visualization

## Objective
The objective of this project is to transform raw UPI transaction data into meaningful visual insights that help understand transaction behavior, identify trends, monitor transaction performance, and explore potential fraud patterns.
